  <h1>Calculadora de IMC</h1>

  <p>
    Aplicativo desenvolvido com <strong>Flutter</strong> e <strong>Dart</strong>
    para calcular o Índice de Massa Corporal (IMC).
  </p>

</div>

---

<h2>Sobre o projeto</h2>

<p>
  A calculadora permite informar o peso e a altura para obter o IMC,
  apresentando a classificação correspondente ao resultado.
</p>

<h2>Funcionalidades</h2>

<ul>
  <li>Cálculo automático do IMC.</li>
  <li>Classificação do resultado.</li>
  <li>Limpeza dos campos para um novo cálculo.</li>
  <li>Interface simples e intuitiva.</li>
</ul>

<h2>Tecnologias</h2>

<ul>
  <li>Flutter</li>
  <li>Dart</li>
</ul>
